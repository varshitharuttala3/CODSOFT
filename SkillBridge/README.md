SkillBridge – Internship & Course Recommendation System

SkillBridge is a content-based recommendation system that suggests internships and courses based on user skills.

Objective

To build a recommendation engine using text similarity techniques.

Features

Skill-based recommendations

TF-IDF vectorization

Cosine similarity scoring

Match percentage calculation

Streamlit-based web interface

Technologies Used

Python

Pandas

Scikit-learn

Streamlit

Outcome

Provides personalized internship and course suggestions based on user input skills.
