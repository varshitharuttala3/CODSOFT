Artificial Intelligence Internship – CODSOFT

This repository contains the projects completed as part of the Artificial Intelligence Internship program at CODSOFT.

🔹 Projects Included
1️⃣ BrainBot Arena – Tic Tac Toe AI

An AI-powered Tic Tac Toe game built using the Minimax algorithm. The AI player makes optimal moves and is unbeatable.

2️⃣ Smart Chatbot – Rule-Based NLP System

A chatbot developed using conditional logic and pattern matching to respond to user queries based on predefined rules.

3️⃣ SkillBridge – Internship & Course Recommendation System

A content-based recommendation system that suggests internships and courses based on user skills using TF-IDF and cosine similarity.

4️⃣ PixCap AI – Image Captioning System

An AI-powered image caption generator using Vision Transformer and GPT-2 to generate contextual and social media-friendly captions.
