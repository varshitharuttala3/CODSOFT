PixCap AI – Image Captioning System

PixCap AI is an AI-powered image captioning system that generates descriptive and social-media-ready captions for images.

Objective

To combine computer vision and natural language processing using pre-trained transformer models.

Features

Image feature extraction

Caption generation using Vision Transformer + GPT-2

GPU acceleration in Google Colab

Social media styled captions and hashtags

Technologies Used

Python

PyTorch

Transformers

Streamlit

Computer Vision

Outcome

Generates contextual captions for uploaded images using deep learning models.
